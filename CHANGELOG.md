# Changelog

## [Unreleased]

## [1.1.0] - 2026-10-24

### Added

- Configurable separator between column indicators.

### Changed

- Improve column rendering and event-handling performance.

### Fixed

- Clear stale column focus when a window update reports that the focused window has lost focus.

## [1.0.0] - 2026-09-10

### Added

- Column indicators for niri's scrolling layout.
- JSON output for Waybar custom modules.
- Plain text output for other status bars.
- Horizontal and vertical layouts.
- Configurable active and inactive indicators.
- Option to hide the indicator for a single column.
